Reading the board honestly

A board row says a protocol records no token in the snapshot — never that it has none; DefiLlama's record can lag a launch. The implied value is this radar's own estimate of what a token would be worth if the protocol's record stayed as it is. It is not a prediction that a token will launch, or when, and it is not make.fun's claim — it is the entry's.
